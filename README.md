## پشتیبان یک‌فایلی
1. **موقع ورود:** فایل `tariq-paya-backup.json` را انتخاب کنید و تأیید کنید «همین است؟»
2. **حین کار:** دکمه «ذخیره پشتیبان» همان یک فایل را به‌روز می‌کند
3. **قبل از خروج:** اگر تغییر ذخیره‌نشده باشد مرورگر هشدار می‌دهد
4. **دستگاه جدید:** فقط همان JSON را بارگذاری کنید — همه اطلاعات برمی‌گردد

در Chrome/Edge ویندوز می‌تواند مستقیم روی همان فایل بنویسد؛ در اندروید با دانلود/آپلود همان نام فایل کار می‌کند.
